# Open Exercise Illustrations

These frames come from **Open Exercise Illustrations**, published by **Hitman Repo**: <https://github.com/hitmanrepo/open-exercise-illustrations>.

- License: [CC0 1.0 Universal (public domain dedication)](https://creativecommons.org/publicdomain/zero/1.0/). The full legal code is in `LICENSE.txt`. No attribution is legally required; Forge credits the source anyway.

## Provenance and caution

The upstream README states that the illustrations are **AI-generated** and "not reviewed by a qualified coach or medical professional." It also says that grip, cable paths or machine geometry can be imperfect, and that equipment may shift between frames.

Because of that, Forge applies a stricter check than for the hand-drawn sources. Each frame used here was inspected individually for:

- the correct equipment;
- body position;
- start and end positions;
- grip;
- any anatomical or equipment errors.

Only 22 exercises passed that check. The app labels these frames as AI-generated wherever their credit appears.

## Changes made for Forge

- Images were resized to 480 px tall and re-encoded as WebP.
- Files were renamed from `images/<id>/{start,mid,end,hold}.webp` to `<id>-N.webp`, in playback order.
- In the app, two frames cross-fade in a loop and three frames play start → mid → end → mid. Single-image holds are shown still.
